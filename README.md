# Black-Hat-Python

Just my workspace as I go through Black Hat Python v2 by Justin Seitz and Tim Arnold, as well as other python projects


- caesar.py will take metasploit shellcode for a c++ console program, perform a caesar cipher and then reformat the code, while using a custom buffer name. reads from a file.
- decrypt-aes-payload.py will take an encrypted aes payload or text from a supplied file and perform a decrypt function. requires pycryptodome: ```pip install pycryptodome```
